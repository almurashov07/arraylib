# arraylib — лабораторная работа № 2

Библиотека операций над массивами целых чисел на C++17.

Работа выполнена в VS Code и WSL (Ubuntu). Для сборки используются g++ и CMake, для контроля версий — Git.

## Функции библиотеки

- `arr_sum` — сумма элементов.
- `arr_max` и `arr_min` — максимальный и минимальный элементы.
- `arr_average` — среднее арифметическое.
- `arr_count_positive` — количество положительных элементов.
- `arr_count_negative` — количество отрицательных элементов.
- `arr_count_zero` — количество нулевых элементов.
- `arr_product` — произведение элементов.
- `arr_median` — медиана без изменения исходного массива.

Функции принимают указатель на массив и его размер типа `std::size_t`. Массив должен быть непустым. Среднее и медиана возвращаются как `double`.

## Структура проекта

- `include/arraylib.h` — объявления функций и макрос экспорта.
- `src/arraylib.cpp` — реализация библиотеки.
- `main.cpp` — демонстрационная программа.
- `tests/test_unit.cpp` — модульные тесты.
- `tests/test_integration.cpp` — интеграционные тесты.
- `examples/variant_15.cpp` — задача по варианту 15.
- `CMakeLists.txt` — настройки сборки.
- `.github/workflows/ci.yml` — автоматическая сборка и тестирование.

## Сборка и запуск в WSL

Команды выполняются из корня проекта:

```bash
cmake -S . -B build
cmake --build build
./build/app
```

CMake собирает динамическую библиотеку `libarraylib.so`, демонстрационные программы и тесты.

## Запуск тестов

```bash
cd build
ctest --output-on-failure
cd ..
```

В проекте зарегистрированы два теста: `unit` и `integration`.

## Вариант 15 — «Тепловая карта»

Исходные температуры:

```text
18 21 25 29 31 27 23 20 17 33 28 24
```

Программа вычисляет сумму, максимум, минимум, среднее и количество значений строго выше 27 градусов.

Сборка и запуск:

```bash
cmake --build build --target variant_15
LD_LIBRARY_PATH=build ./build/variant_15
```

Ожидаемые результаты:

```text
Сумма значений: 296
Максимальная температура: 33
Минимальная температура: 17
Средняя температура: 24.67
Количество значений выше 27 градусов: 4
```
